# Roadmap

## 0.1.x: dependable local authoring

- Improve archetype recommendation against a reviewed, synthetic evaluation set.
- Add better edge routing, crowded-layout handling, and richer diagram legends.
- Align runtime validation more fully with the published JSON Schema.

## 0.2.x: paper-assisted drafting

- Add provider adapters behind the current explicit opt-in boundary.
- Preserve section/page anchors for PDF and DOCX text extraction.
- Provide an interactive review step for claims, nodes, relations, and layout alternatives.
- Add evaluation reports for extraction coverage and relationship errors.

## 0.3.x: authoring and export

- Add an optional local editing UI with position locking and direct label editing.
- Improve print-size typography checks and stable PNG/PDF export on supported platforms.
- Add accessibility checks for color contrast and non-color semantic cues.

Milestones depend on maintainer capacity and community feedback. No target date or universal automatic-accuracy claim is implied.
