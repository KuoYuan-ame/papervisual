# 参考图视觉风格与复用流程

`reference` 是原生 SVG 主题。它借鉴用户参考图的构图、层级和配色，图标由矢量基本形状原创绘制。主题没有捆绑参考截图或用户论文；渲染不调用图像模型。它不是逐像素复刻器。

## 视觉规则

以 1007 × 625 的设计坐标为起点，默认采用约 1.61:1 的横向比例。顶部总览下方会显示一行图级主张，主体分栏占主要面积，底部为独立图注；节点较多或图注较长时允许画布增高。

| 元素 | 规则 |
|---|---|
| 总览 | 左侧前三个节点；中间主标题与分组缩略图；右侧仅展示图中实际使用的角色颜色 |
| 主体 | 2–4 个浅灰分栏，深蓝标题带，灰色连接形状 |
| 角色颜色 | 蓝 `#315b9b`、绿 `#4c8a37`、橙 `#ef7100`、红 `#c80013`；颜色表示角色，不表示证据强弱 |
| 线条 | 设计坐标内约 1.2–1.5 px；分组虚线、扁平小图标；避免阴影和渐变 |
| 字体 | 无衬线标题/标签；英文图注 Times New Roman；含中文时优先微软雅黑 |
| 稀疏栏 | 根据已有入边，重复显示来源节点的小型引用；不是新增科学模块 |
| 条件标签 | 节点可有最多两个来源支持的短注释；没有依据就不填 |

灰色标题间连接形状只表示栏位顺序。科学关系由实际边的 `relation` 决定；`association` / `contrast` 不加箭头。理论论文应区分 `proof_dependency`（证明依赖）和 `specialization`（一般结果的特殊化），不能只靠边标签解释两种不同逻辑。所有边保留来源和审核状态。单节点栏中的小型来源引用及其关系标签来自真实入边；图上重复出现同一标签不代表存在两个实体。

## 适配标签与图例

### 固定风格与可变内容

保留白底横向画布、顶端左/中/右总览、中央主标题、单句主张、深蓝分栏标题带、浅灰栏底、圆角虚线卡片和底部衬线图注。以设计坐标计，主体从 y=168 开始，栏间距 7、左右边距 16、标题带高度 33；卡片线宽约 1.5、圆角 9，虚线节奏 5/3。正文为无衬线，正文基准 11，卡片标题 13.5，栏标题 14，图注 15。这些值随输出整体等比缩放，不代表印刷字号。

可以随论文调整分栏名、节点数、文字、真实关系、短条件、副标题、图例含义与重复来源引用的显示。不要改成阴影卡片、渐变底色、照片拼贴或大面积装饰插画。先改变叙事和短语以适配密度，不能以持续缩小字体解决过长内容。排版到目标宽度时另查物理字号；高分辨率 PNG 本身不会改善小字。跨越同栏中间卡片的关系沿左侧栏内边距绕行，避免看成中间节点导出的新关系。

技能包的 `assets/reference.png` 和 `assets/reference.svg` 是公开可分发的原创视觉锚点；它们与文档和渲染器一起保存样图的视觉逻辑，无需旧对话截图。新论文只采用其美术规则，不继承合成例子的科学内容。

默认面板副标题（例如 `Incoming relationships`）和角色图例（例如 `Output / special case`）是通用回退文本，不一定适合每篇论文。用 `panel_descriptors` 逐栏设置副标题；传空字符串可隐藏副标题。用 `legend_labels` 按颜色覆盖图例名称；渲染器只显示节点实际使用的角色颜色，并在有待核对内容时显示红色。稀疏栏的来源缩略卡及下游提示默认开启以保留样图特征；设置 `show_crossrefs: false` 可以隐藏这些重复引用，只保留真实连线。

```json
{
  "panel_descriptors": {
    "design": "Architecture and skill acquisition",
    "applications": "Representative settings",
    "evaluation": "Complementary lenses",
    "challenges": "Open research questions"
  },
  "legend_labels": {
    "blue": "Framework / evaluation",
    "green": "Application domains",
    "red": "Open challenges / author review"
  },
  "show_crossrefs": false
}
```

综述的副标题应描述文献分类或文章结构，避免实验术语。先缩短节点标签，再用图注承载完整解释；页码放在 `source` 元数据中，不要塞进卡片注释。章节顺序不能暗示因果或系统执行流程。

## 最小用法

从 `../assets/reference.json` 复制图稿。设置 `"style": "reference"`，给所有节点填写 `panel`，用 `panel_labels` 将分组 ID 映射为简短的显示标题；按论文需要设置 `panel_descriptors` 与 `legend_labels`；可选 `caption` 和节点 `annotations`。`annotations` 当前仅在 reference 主题中绘制。

```powershell
papervisual validate ../assets/reference.json
papervisual render ../assets/reference.json -o work/reference.svg --png work/reference.png --pdf work/reference.pdf
papervisual qa ../assets/reference.json --svg work/reference.svg --output work/reference.qa.json
```

PNG/PDF 需要安装 `.[raster]`。SVG 保留文字、形状和来源元数据。PNG 按实际 SVG 尺寸的两倍导出，避免根据原始 brief 尺寸强制拉伸。字体由运行环境提供；换系统必须重新目视检查，当前没有自动缺字检测。

## 新论文的适配顺序

1. 先识别论文类型和独有贡献，再提取“问题/对象 → 决定性方法或引理 → 主结果 → 推论与边界”的最短论证链。不要把章节目录直接画成图；附件内容作为材料分析。
2. 根据论文逻辑分成 2–4 栏，例如实验论文的“输入—处理—证据—输出”，或理论论文的“基础—关键引理—一般定理—特殊情形”。不要强行套用数学案例的术语。
3. 保持每栏通常 1–3 个关键节点。单节点栏的入边引用由主题生成；不额外编写虚构方法来填空。节点过多时先压缩叙事，不以极小字号解决。
4. 将节点标题写成短词组，`detail` 放定理编号、方法对象或证据编号，`annotations` 放最多两条短条件。长假设与限制进入图注或配套报告。
5. 读者可见文字默认用英文，除非用户明确指定其他语言；来源锚点可保留原文。将未核对内容标为 `needs_review`。运行结构校验和渲染，再查看完整 PNG、PDF 页面和拟排版尺寸，检查字体、箭头、标签、跨栏连线及图注。若无 Cairo，则用可用 SVG 查看器按最终尺寸检查，记录工具、目标宽度和未导出的格式；若查看器不可用，明确记录人工视觉 QA 未完成。自动 QA 或导出成功不代表完整视觉验收。
6. 修订 brief 后从源 SVG 重新导出。交付 JSON、SVG、PNG/PDF、QA 和科学核对清单。

## 当前边界

此主题不自动阅读 PDF，也不独立验证公式或箭头所表达的科学关系。自动 QA 使用主题实际节点坐标检查边界，但仍是结构和近似文字检查；它不是完整的文字碰撞、缺字或任意图避障系统。设计适合短标签和少量入边；极密图、多语言混排或长公式仍需人工调整。英文图注、中文图注和最终排版字号均须在目标机器复查。
