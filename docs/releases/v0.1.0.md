PaperVisual's first public MVP produces editable graphical abstracts and one-figure paper overviews from reviewed, source-grounded JSON research briefs.

Features:

- Six deterministic layouts with explainable relationship-based recommendations.
- A compact reference theme with 2–4 panels, original vector icons and source-backed condition tags.
- Native SVG labels, shapes, arrows, relation legends and visible draft notices; Mathtext equations are vector paths retaining TeX for rerendering.
- Local batch rendering, per-figure QA and a machine-readable summary.
- Optional PNG/PDF export from the same SVG via CairoSVG.
- Optional text-to-brief adapter organized around paper type, specific contribution, evidence and scope; English is the default figure language, with Chinese available explicitly. All generated content requires review.
- Separate proof-dependency and specialization arrows, independent edge labels, and a layered theory style with a dominant theorem and adjacent assumptions/equality.
- Source presence gates for the claim, nodes and edges; absent review status defaults to needs_review, with author confirmation checked independently.
- Final physical width, minimum point size, PNG DPI and optional measured glyph/text/collision audits; an early doctor command diagnoses dependencies.
- Eight original synthetic examples, bilingual documentation and a reusable conversation handoff workflow.
- A standalone Skill ZIP with bundled offline renderer, original visual anchors, default-English synthesis instructions, schema and file hashes. Extract the entire folder and run its `scripts/papervisual.py`; the wheel alone does not install this Skill.
- A portable `scripts/self_check.py` command checks dependencies, manifest integrity, the four CLI steps and deterministic SVG replay. Visual QA is recorded separately: SVG-viewer inspection is the fallback without Cairo, and lack of a viewer leaves visual QA incomplete.

Install from the attached wheel with `python -m pip install papervisual-0.1.0-py3-none-any.whl`, or download and unpack the source distribution to run the examples. Run `papervisual init` to start without an API key. See README for batch generation and optional exports. This release is on GitHub; it is not a PyPI publication.

Validation includes unit/regression tests, clean wheel installation, schema checks, editable SVG structure and deterministic fixtures, plus PNG/PDF export smoke tests. Checksums for the distribution files are attached.

Known limits: early alpha/MVP; no PDF/DOCX importer, visual editor, general obstacle-routing solver or independent scientific fact verification. Model integration is mock-tested, not benchmarked on real papers. Complex figures may need manual edits. The author must verify scientific meaning and final readability; QA success is not submission clearance.
