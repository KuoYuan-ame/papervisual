# Contributing

Contributions are welcome through GitHub issues and pull requests.

## Before opening a pull request

- Keep layout selection explainable and preserve explicit user overrides.
- Do not add inferred scientific relationships without marking them for review.
- Add or update tests for schema, layout, rendering, or QA behavior.
- Use only original or clearly licensed examples, fonts, and icons.
- Run `python -m unittest discover -s tests -v`.

## Scope

The project prioritizes robust editable SVG output and transparent paper-to-figure structure. Large framework dependencies, provider-specific model integrations, and copyrighted paper figures require prior discussion in an issue.
